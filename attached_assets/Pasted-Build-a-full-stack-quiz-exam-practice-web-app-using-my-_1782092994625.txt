  App goal:
  Create a user-specific exam practice app. Each user should have their own
  saved progress, attempts, scores, wrong-answer notebook, and review
  history.

  If full authentication is too heavy, implement a simple username/email
  login system, but all saved data must be tied to user_id.

  Core modes:

  1. Mockup Practice Mode
  - Use questions where exam_sources.is_real_test = 0.
  - Allow repeated practice.
  - Include a configurable time limit.
  - Users can check correctness during the attempt.
  - Show immediate feedback after answering.
  - Store attempt history.
  - Store per-question answers.
  - Store wrong answers in an 오답노트 / wrong-answer notebook.
  - Users can review and retry wrong answers later.

  2. Real Test Mode
  - Use questions where exam_sources.is_real_test = 1.
  - Strict 2-hour time limit.
  - Full score is 1000 points.
  - Passing score is 720 points.
  - Do not reveal correctness question-by-question during the real test.
  - Only show final result after submission or timer expiration.
  - Final result must include:
    - total score out of 1000
    - pass/fail
    - correct count / total count
    - scenario/category-level score breakdown
    - wrong answer list
  - Store real test attempts separately from mockup attempts.
  - Store real test wrong answers into the wrong-answer notebook.

  Scoring:
  - Real test score = correct_count / total_questions * 1000.
  - Passing score = 720.
  - Category/scenario score should group by exam_questions.scenario.
  - Mockup score can show percent correct and correct/total.
